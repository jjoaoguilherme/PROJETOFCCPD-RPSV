1. Execute `./mvnw.cmd clean test` no Windows.
2. Confirme que o repositorio remoto contem todos os commits.
3. Ensaiem o roteiro e ajustem os nomes das pessoas.
4. Levem o projeto aberto no commit mais recente para a demonstracao.
